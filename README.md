# Линейная алгебра код к трём частям

Программы к книгам Аботалеба Мостафы Салахелдина Абделсалама. В книгах и репозитории 264 кодовых блока.

| Книга | Материалы | Кодовые блоки |
| --- | --- | --- |
| Матрицы векторные пространства и линейные коды | [Часть 1](Part_1) | 100 |
| Спектральная теория и геометрические приложения | [Часть 2](Part_2) | 88 |
| Методы приближения и вычислительное моделирование | [Часть 3](Part_3) | 76 |

## Как выполнить пример

1. [Скачайте архив](https://github.com/abotalebmostafa11/Linear-Algebra-Wolfram/archive/refs/heads/main.zip) и распакуйте его.
2. Выберите часть и главу. Откройте файл с расширением `.nb` в Wolfram Mathematica.
3. Перед самостоятельным примером выполните `Quit[]` в отдельной ячейке.
4. Вычислите ячейку примера клавишами Shift+Enter.

Новый блокнот сам по себе не очищает память ядра. Матрицы, векторы и параметры уже включены в каждый самостоятельный пример.

Шесть ячеек проекта третьей части, раздела 3.9, используют общие данные. Выполняйте их по порядку в одном ядре без `Quit[]` между ними.

Файлы `.wl` показывают тот же код в текстовом виде. Скопируйте выбранный пример целиком в ячейку Mathematica и нажмите Shift+Enter.

Копия данных проекта находится в [cars.csv](Part_3/data/cars.csv). Столбцы содержат скорость в милях в час и расстояние в футах. Источник — [набор cars системы R](https://stat.ethz.ch/R-manual/R-devel/library/datasets/html/cars.html).
