# Линейная алгебра код к трём частям

Программы к книгам Аботалеба Мостафы Салахелдина Абделсалама. Текущая редакция содержит 603 блока кода и 315 задач с математическими решениями. Код извлечён из рукописей без добавления исполняемых оболочек.

| Часть | Основной текст | Решения 15 задач на главу | Исследования условий | Всего блоков |
| --- | --- | --- | --- | --- |
| [Часть 1](Part_1) | 100 | 135 | 8 | 243 |
| [Часть 2](Part_2) | 88 | 120 | 8 | 216 |
| [Часть 3](Part_3) | 76 | 60 | 8 | 144 |

## Выполнение

1. [Скачайте архив репозитория](https://github.com/abotalebmostafa11/Linear-Algebra-Wolfram/archive/refs/heads/main.zip).
2. Откройте файл `.nb` нужной главы в Wolfram Mathematica.
3. Выполните `Quit[]` в отдельной ячейке перед самостоятельным примером.
4. Вычислите выбранную ячейку целиком клавишами Shift+Enter.

Новый блокнот не очищает память ядра. В каждой самостоятельной программе заданы её исходные данные. Файлы `.wl` содержат тот же код в текстовом виде.

Шесть ячеек проекта 3.9 третьей части используют общие данные. Выполняйте их по порядку в одном ядре без `Quit[]` между ними.

Число блоков считается по абзацам SourceCode в книгах и входным ячейкам Input в блокнотах. Для третьей части это 76 блоков основного текста + 60 решений задач + 8 исследований = 144 блока.

Данные проекта — [cars.csv](Part_3/data/cars.csv), 50 наблюдений. Источник — [документация набора cars системы R](https://stat.ethz.ch/R-manual/R-devel/library/datasets/html/cars.html). Единицы — мили в час и футы.
