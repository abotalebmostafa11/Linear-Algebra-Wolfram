## Как запустить

1. [Скачайте ZIP](https://github.com/abotalebmostafa11/Linear-Algebra-Wolfram/archive/refs/heads/main.zip) и распакуйте его.
2. Откройте папку нужной части и файл `Chapter_XX.nb` в Wolfram Mathematica.
3. Выберите пример своего раздела и нажмите Shift+Enter.

Перед другим самостоятельным примером перезапустите ядро Mathematica. Шесть блоков проекта части 3, раздела 3.9, выполняйте по порядку в одном сеансе ядра.

Файл `.wl` показывает тот же код в текстовом виде. Для запуска отдельного примера скопируйте его из `.wl` в ячейку Mathematica и нажмите Shift+Enter.

Все исходные матрицы, векторы и параметры уже приведены в коде. Данные проекта `cars` также сохранены в [Part_3/data/cars.csv](Part_3/data/cars.csv). Столбцы содержат скорость в милях в час и тормозной путь в футах. Источник — [набор cars системы R](https://stat.ethz.ch/R-manual/R-devel/library/datasets/html/cars.html).
