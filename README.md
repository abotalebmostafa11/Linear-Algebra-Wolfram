# Линейная алгебра код к трём частям

Текущая редакция содержит 667 блоков кода и 360 задач с математическими решениями. Программы извлечены из рукописей без дополнительных исполняемых оболочек.

| Часть | Главы | Задачи с решениями | Блоки кода |
| --- | --- | --- | --- |
| [Часть 1](Part1) | 9 | 135 | 243 |
| [Часть 2](Part2) | 8 | 120 | 217 |
| [Часть 3](Part3) | 7 | 105 | 207 |

Перед самостоятельным примером выполните `Quit[]` в отдельной ячейке. Затем выполняйте пример целиком. Входная ячейка `.nb` соответствует одному абзацу кода книги. Файл `.wl` содержит те же программы. Новый блокнот не очищает память ядра.

Шесть ячеек итогового проекта раздела 6.9 третьей части выполняйте по порядку в одном ядре без перезапуска. Данные: [cars.csv](Part3/data/cars.csv).

В книгах используются адреса без подчёркиваний. Каталоги предыдущей редакции сохранены для работоспособности ранее напечатанных ссылок и QR-кодов. Их нумерация соответствует предыдущей редакции. Для текущих книг выбирайте ссылки в таблице выше.
