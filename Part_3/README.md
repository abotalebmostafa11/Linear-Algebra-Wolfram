# Часть 3 Методы приближения и вычислительное моделирование

В текущей редакции 144 блоков кода. Каждый блок совпадает с одним абзацем SourceCode рукописи.

Состав: 76 блоков основного текста, 60 решений задач и 8 исследований при изменении условия.

В каждой из 4 глав — 15 задач. Уровень 1 содержит пять задач на операции, уровень 2 — пять задач на применение, уровень 3 — пять задач на доказательства и исследование.

Откройте блокнот главы. Перед самостоятельным примером выполните `Quit[]` в отдельной ячейке, затем вычислите выбранную ячейку клавишами Shift+Enter. Новый блокнот сам по себе не очищает ядро.

Файлы `.wl` содержат те же программы. Копируйте один пример целиком. Для доказательств код проверяет указанное тождество или пример, а общий аргумент приведён в книге.

Шесть ячеек итогового проекта раздела 3.9 выполняйте последовательно в одном ядре без перезапуска между ними. Копия данных — [cars.csv](data/cars.csv).
