# Часть 3 Методы приближения и вычислительное моделирование

В этой части 76 кодовых блоков. Примеры совпадают с книгой.

Откройте блокнот нужной главы. Перед самостоятельным примером выполните `Quit[]` в отдельной ячейке. Затем вычислите выбранную ячейку клавишами Shift+Enter. Новый блокнот сам по себе не очищает ядро.

Файлы `.wl` содержат те же примеры. Копируйте один пример целиком в ячейку Mathematica.

Шесть ячеек проекта раздела 3.9 выполняйте последовательно в одном ядре. Сначала выполните ячейку с данными. Между ячейками проекта не выполняйте `Quit[]`. Данные уже включены в код. Копия находится в [cars.csv](data/cars.csv).
