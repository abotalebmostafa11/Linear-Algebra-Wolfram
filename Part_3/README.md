# Часть 3

67 кодовых блоков. Имена файлов соответствуют нумерации глав книги.

Сначала скачайте и распакуйте [весь репозиторий](https://github.com/abotalebmostafa11/Linear-Algebra-Wolfram/archive/refs/heads/main.zip). ## Запуск и данные

- `Run_All.nb` — запуск всех примеров этой части из Mathematica.
- `Run_All.wls` — запуск через `wolframscript -file Part_3/Run_All.wls` из корня репозитория.
- `examples.json` — исходный код с идентификаторами, разделами, зависимостями и контрольными суммами.
- `data/inputs.json` — числовые входные присваивания из программ.
- Результаты выполнения сохраняются в `results/execution_part_3.json` в корне репозитория.

Все входные данные включены в программы. Набор `cars` также сохранен в `data/cars.csv`; `Load_Cars.wl` читает его без сети.
