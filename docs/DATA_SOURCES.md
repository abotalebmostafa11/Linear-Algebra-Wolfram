# Источники данных

Части 1–3 используют числовые матрицы, векторы, параметры и конечные поля из соответствующих примеров книги. Эти входные значения сохранены в коде каждого примера. Файл `Part_N/data/inputs.json` содержит указатель буквальных числовых присваиваний в точной записи Wolfram Language. Вычисляемые и символические определения остаются в программах.

## Набор cars

В проекте раздела 3.9 части 3 используются 50 наблюдений набора `cars` из пакета `datasets` системы R. Первая колонка — скорость в милях в час, вторая — расстояние остановки в футах. Строки сохранены в исходном порядке. Данные находятся в `Part_3/data/cars.csv`; схема колонок — в `cars.schema.json`.

- [Описание набора в документации R](https://stat.ethz.ch/R-manual/R-devel/library/datasets/html/cars.html)
- [Файл данных проекта R](https://svn.r-project.org/R/trunk/src/library/datasets/data/cars.R)

Описание R ссылается на M. Ezekiel, Methods of Correlation Analysis, Wiley, 1930. Имена колонок CSV уточняют единицы измерения; числовые значения не изменены. Для повторения проекта сеть не требуется.
