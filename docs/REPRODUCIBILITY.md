# Воспроизведение и проверка

## Что проверено при подготовке

- Все 251 блока входного архива совпадают с входными ячейками его 16 ноутбуков.
- Все 255 вхождений кода в трех книгах совпадают с кодом входного архива. Четыре дополнительных вхождения возникают при повторении двух справочных программ в трех частях.
- Нумерация 21 ноутбука соответствует главам трех книг.
- SHA-256, целостность текстовых файлов, парность скобок и соответствие кода `.nb`, `.wl` и каталогу проверяются `tools/check_package.py`.
- Все 50 строк `cars.csv` совпадают с двумя векторами проекта в книге.

## Проверка ядром Wolfram

Среда подготовки не содержит ядра Wolfram. Фактическое выполнение всех программ в Mathematica здесь не проводилось. Сохраненных или подставных результатов вычислений в ноутбуках нет.

`Run_All.nb` и `Run_All.wls` выполняют исходный код, сохраняют результаты и сообщения вместе с версией ядра и платформой. Для 144 численных вариантов практикума и шести блоков проекта предусмотрены проверки математических равенств. `NotSpecified` означает, что для демонстрационного блока отдельный проверочный предикат не задан. Отсутствие сообщений само по себе не означает математическую проверку результата.

Независимые примеры выполняются в отдельных контекстах. Шесть блоков проекта cars используют один контекст и выполняются по порядку. При отказе зависимого блока следующие блоки проекта получают статус `SkippedDependency`.

В Mathematica выполните `TestReport[FileNameJoin[{root,"tests","Book_Examples.wlt"}]]`, где `root` — путь к распакованному репозиторию. Файл содержит 150 проверок исходных примеров. Ожидаются точные равенства; сравнение QR и SVD в проекте использует допуск для 40-значной арифметики.

## Важные соглашения

Координаты векторов трактуются как столбцы в математических формулах. У `QRDecomposition` хранится транспонированная ортогональная часть, поэтому программы используют `ConjugateTranspose[qStored]`. Проверять разложения следует по восстановлению матрицы; собственные векторы могут отличаться масштабом и знаком. Точные дроби не заменяются десятичными приближениями во входных данных.

Документация Wolfram [CellContext](https://reference.wolfram.com/language/ref/CellContext.html), [ToExpression](https://reference.wolfram.com/language/ref/ToExpression.html), [QRDecomposition](https://reference.wolfram.com/language/ref/QRDecomposition.html).
