## Запуск и данные

- `Run_All.nb` — запуск всех примеров этой части из Mathematica.
- `Run_All.wls` — запуск через `wolframscript -file Part_2/Run_All.wls` из корня репозитория.
- `examples.json` — исходный код с идентификаторами, разделами, зависимостями и контрольными суммами.
- `data/inputs.json` — числовые входные присваивания из программ.
- Результаты выполнения сохраняются в `results/execution_part_2.json` в корне репозитория.

Все входные данные включены в программы. Подключение к сети для вычислений не требуется.
